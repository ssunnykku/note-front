# 휴지통 & 미분류 노트 기획

## 개요

노트 삭제 시 즉시 영구 삭제하지 않고 휴지통에 보관하며, 카테고리에 속하지 않은 노트도 허용한다.

## 노트 생성 진입점

두 가지 방식으로 노트를 생성할 수 있다.

| 진입점 | 위치 | 결과 |
| --- | --- | --- |
| **카테고리 하위 `+` 버튼** | 사이드바 카테고리 항목 hover 시 | 해당 카테고리에 노트 생성 |
| **빠른 메모 버튼** | 사이드바 상단 | 미분류 상태로 노트 생성 |

## 미분류 노트

- 카테고리 없이 생성된 노트는 "미분류" 섹션에 표시
- 미분류는 시스템 섹션으로 사용자가 삭제/이름변경 불가
- 나중에 카테고리로 이동 가능 (추후 구현)

## 휴지통

### 삭제 흐름

1. 사이드바 노트 항목 hover → 삭제 아이콘 표시
2. NoteContent 헤더 우측 → 삭제 아이콘 표시
3. 삭제 클릭 → 확인 모달 → soft delete API 호출
4. 노트가 기존 목록에서 제거되고 휴지통으로 이동

### 휴지통 UI

- 사이드바 최하단에 "휴지통" 섹션 고정
- 휴지통 클릭 시 삭제된 노트 목록 표시
- 각 노트에 **복원**, **영구 삭제** 버튼 제공

### 백엔드 API (soft delete 지원)

| 동작 | API |
| --- | --- |
| 삭제 (soft delete) | `DELETE /notes/{id}` |
| 휴지통 목록 조회 | `GET /notes/trash` |
| 복원 | `PATCH /notes/{id}/restore` |
| 영구 삭제 | `DELETE /notes/{id}/permanent` |

## 사이드바 구조

```
[+ 빠른 메모]
─────────────
미분류 (3)
  새 노트
  메모 1
  아이디어
─────────────
📁 프로젝트 (5)
📁 일상 (2)
─────────────
🗑 휴지통
```

## 삭제 버튼 위치

| 위치 | 트리거 | 용도 |
| --- | --- | --- |
| 사이드바 노트 항목 | hover 시 🗑 아이콘 | 목록에서 빠르게 삭제 |
| NoteContent 헤더 우측 | 항상 표시 또는 더보기 메뉴 | 노트를 열어본 상태에서 삭제 |
