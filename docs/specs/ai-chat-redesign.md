# 기획 수정안

## 현재 구조

```
카테고리 ← 1:N → 노트
카테고리 ← 1:N → 채팅 (최대 5개, 사이드바에서 바로 생성)
```

- 사이드바에서 "기록/AI 채팅" 탭 전환
- 채팅이 카테고리에 직접 종속

## 변경 후 구조

```
카테고리 (사용자 생성) ← 1:N → 노트(메모)
AI 모델 (허깅페이스에서 주제별로 학습시킨 모델)
채팅 = 카테고리 + AI 모델 조합
```

### 데이터 관계

- 카테고리 1 → 채팅 N (하나의 카테고리에 여러 채팅 생성 가능)
- 채팅 1 → 카테고리 1 (하나의 채팅은 하나의 카테고리만 참조)
- 채팅 1 → AI 모델 1 (채팅마다 다른 AI 모델 선택 가능)
- 채팅 생성 수 제한 없음

## 사용자 흐름

1. **카테고리 생성** → 사용자가 직접 만듦
2. **메모 작성** → 카테고리 안에 노트 작성
3. **AI 탭 진입** → "새 채팅" 버튼 클릭
4. **카테고리 선택** → 내 노트 카테고리 중 선택하여 채팅 생성
5. **AI 첫 메시지** → "어떤 주제로 대화를 나눌까요?" + 주제별 AI 모델 목록 표시 (버튼/칩 형태)
6. **AI 모델 선택** → 해당 모델이 채팅에 연결, 태그로 표시
7. **대화 시작** → 선택한 카테고리의 노트가 AI 컨텍스트로 활용됨

## 채팅 목록 UI

```
채팅 목록
├── 채팅 1  카테고리: 프로젝트A  | AI: 개발
├── 채팅 2  카테고리: 프로젝트A  | AI: 학습
├── 채팅 3  카테고리: 일상메모   | AI: 일상
```

- 채팅 목록은 플랫 리스트 (카테고리별 그룹핑 없음)
- 각 채팅에 카테고리명 + AI 모델 태그 표시

## AI 모델

- 주제별로 학습시킨 모델
- 채팅 생성 후 첫 대화에서 선택

## 요약

| 항목          | 현재                             | 변경 후                                       |
| ------------- | -------------------------------- | --------------------------------------------- |
| 카테고리 생성 | 백엔드에서 관리                  | 사용자가 UI에서 생성                          |
| 채팅 생성     | 사이드바 카테고리 하위, 최대 5개 | "새 채팅" 버튼, 제한 없음                     |
| AI 모델       | 없음                             | 주제별 학습 모델 선택 (채팅 내 첫 메시지에서) |
| 채팅 목록     | 카테고리별 그룹                  | 플랫 리스트 (카테고리+AI 태그 표시)           |
| AI 컨텍스트   | 없음                             | 선택한 카테고리의 노트를 컨텍스트로 활용      |

## 결정 사항

- **AI 사이드바**: 기존 노트 카테고리 구조에서 **분리**한다. 현재 탭 전환 + 카테고리 공유 구조를 리팩토링.
- **채팅 목록 정렬**: **최신순**으로 정렬한다.
- **AI 모델 변경**: 채팅 생성 후 모델 변경 **불가**.
