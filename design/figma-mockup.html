React 컴포넌트 설계 질문
사이드바 컴포넌트가 너무 커졌는데, 어떻게 분리하면 좋을까요?
사이드바를 기능 단위로 분리하는 것을 추천드립니다. 예를 들어:

1. SidebarNoteList - 노트 목록 렌더링
2. SidebarChatList - 채팅 목록 렌더링
3. SidebarCategoryGroup - 카테고리 그룹

각 컴포넌트는 자체 상태를 관리하고, 부모로부터 콜백만 받는 구조가 좋습니다.
카테고리 그룹 컴포넌트의 props는 어떻게 설계하면 좋을까요?
핵심 props만 전달하세요:

interface CategoryGroupProps {
  category: Category;
  isOpen: boolean;
  onToggle: () => void;
  children: ReactNode;
}

노트 아이템 렌더링은 children으로 위임하면 유연합니다.
